# Support

Engram is currently a release-candidate project maintained on a best-effort
basis. There is no guaranteed response time or support contract.

Use the channel that matches the request:

- Usage and integration questions: open a
  [question](https://github.com/ontopix/engram/issues/new?template=question.yml).
- Reproducible defects: use the
  [bug report](https://github.com/ontopix/engram/issues/new?template=bug_report.yml).
- Standard changes: use the
  [specification proposal](https://github.com/ontopix/engram/issues/new?template=spec_change.yml)
  before preparing a normative patch.
- CLI or documentation improvements: use the
  [feature request](https://github.com/ontopix/engram/issues/new?template=feature_request.yml).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and do not post
  details publicly.

Before opening a question, check the [README](README.md),
[operator guide](docs/operator-guide.md), and existing issues. Include the
exact `engram version --format json` output when behavior may depend on the
binary, specification revision, Git, or operating system. Remove credentials,
private paths, and real memory content from all diagnostic output.
