## Placement

Use one `journal-entry@v1` per local event date under its calendar-year directory.
Create a year's README in the same operation as its first record. Daily records
use fixed date descriptions and append-only chronological blocks; add labels
inside the body rather than inserting material into earlier sections.

Record only useful evidence and its observed source. A missing day is unknown,
not proof of no activity. Use the root map's calendar and late-evidence rules.

## Navigation

Find a known date by filename. For a broader question, search daily content and
follow the relevant year map; date-addressed records do not need a long catalog.
