## Placement

Use `period-review@v1` records under the ISO week-year directory. A week runs from
Monday through Sunday in the root map's calendar. Review closed periods with
available evidence; explain gaps instead of manufacturing a full chronology.

Use the same path when corrections materially change a review. A review
records an editorial assessment and its rationale, not a current project status.
