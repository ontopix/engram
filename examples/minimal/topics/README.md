# topics

Free-form notes, one topic per record, kebab-case filenames. Each note
stands alone: its first sentence summarizes it, and related notes are
wikilinked rather than restated.

## Map

<!-- engram:catalog -->
- [derived-state](derived-state.md) — Indexes and caches are rebuildable projections; the files stay the truth.
- [why-files](why-files.md) — Why this store is plain markdown files instead of a database.
<!-- /engram:catalog -->

## Placement

Any self-contained topic that fits `note`. If a third note about the
same kind of thing appears, that is a missing type — define it in
`.engram/schemas/` instead of forcing structure into notes.
